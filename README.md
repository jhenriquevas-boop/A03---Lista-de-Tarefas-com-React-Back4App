# Lista de Tarefas (React + Back4App)
Uma aplicacao web de lista de tarefas (To Do) desenvolvida em React com Vite e integrada ao Back4App para salvar os dados na nuvem. Permitindo o usuario adicionar, visualizar e excluir as tarefas em tempo real sem perder nada depois ao atualizar a pagina(F5).
